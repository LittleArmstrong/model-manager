## Voraussetzungen

-   Python 3.8 bis 3.13  
    (neuere Versionen wurden nicht getestet)
-   Windows  
    (andere Betriebssysteme wurden bisher nicht getestet)

---

## Installation

### 1. Virtuelle Umgebung erstellen

Öffne eine Konsole im Projektordner und führe aus:

```bash
python -m venv .venv
```

Aktiviere anschließend die virtuelle Umgebung:

```bash
.venv\Scripts\Activate.ps1
```

### 2. Abhängigkeiten installieren

```bash
pip install -r requirements.txt
```

## Hinweise

Stelle sicher, dass die richtige Python-Version verwendet wird:

```bash
python --version
```
